# 실내 홈캠 객체 위치 추론 파이프라인 고도화 (사내 R&D)

> VLM 위치추론의 비용·확장성 한계를 규칙기반 엔진 + SAM2 트래킹으로 돌파, Scene Graph Generation과 비교 실험까지
> [CCTV 객체 위치 추론 프로젝트](project_c_vlm.md)(고객사 계약 건)와는 별개로 진행한 회사 자체 데이터 기반 내부 연구입니다.

## 배경 & 목표

VLM 단독 추론은 프레임마다 API를 호출해야 해서, 처리할 영상이 늘어날수록 비용·시간도 그만큼
늘어나는 구조라 확장에 한계가 있었습니다. 이 한계를 규칙기반 엔진으로 돌파하고, 검수 파이프라인을
SAM2 비디오 트래킹으로 고도화한 뒤, 마지막으로 학습 기반 Scene Graph Generation(REACT++)과
비교해 규칙기반 접근의 위치를 가늠해봤습니다.

## 단계별 진행

1. **VLM 기반 위치 GT 생성** — Qwen3-VL로 bbox 단위 위치 GT 파일럿 구축
2. **규칙기반 위치 판정 엔진** — 얼굴/손 키포인트 근접도 + 가구 포함관계 기반 결정론적 판정으로 VLM 대체 (호출 비용 0, 판정 근거 100% 설명 가능)
3. **SAM2 시드-프레임 트래킹** — 프레임 독립 추론(YOLO) 대비 시간축 추적으로 오류(오분류·중복·드리프트) 빈도 감소
4. **REACT++ 비교 실험** — 공개 오픈소스 [SGG-Benchmark](https://github.com/Maelic/SGG-Benchmark)의 REACT++를 우리 데이터로 파인튜닝

## 트러블슈팅

SAM2 트래킹 도입 과정에서 세그멘테이션 마스크 결손(가구 위에 사람이 앉으면 마스크가 반으로 갈라짐),
다중 검수자 동시쓰기로 인한 결과 파일 손상 문제를 직접 규명하고 해결했습니다.

## 성과 / 결론

- VLM 호출 없이 규칙기반 엔진만으로 위치추론 (비용 0, 지연 없음, 판정 근거 설명 가능)
- 프레임 독립 추론(YOLO) 대비 시간축 추적(SAM2)으로 오류 빈도를 낮춰, 검수자가 실제로 고쳐야 하는
  빈도를 줄임 (전체 확인 자체는 여전히 필요)
- REACT++는 규칙기반이 확실히 틀렸던 케이스의 약 70%를 개선했지만, 전체 정확도·속도는 소폭 낮음
  (프레임 정확도 0.818 vs 0.826, 23.4fps vs 30.9fps) — "완전 대체"보다는 트레이드오프 실험으로 해석
